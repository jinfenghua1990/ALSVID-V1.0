# ALSVID Admin Operation System V1.0

> 本文件为简要业务边界摘要，详细 IA 以 `docs/ALSVID_ADMIN_IA.md` 和当前 `business-module-registry.ts` 为准；旧版 Shopify/一级菜单描述已废止。

## 定位

ALSVID Admin 是内部统一运营后台，管理 ALSVID 自建商城的商品、订单与相关业务流程；公开商城在官网，员工管理入口在 Admin。外部支付由获批 PSP 执行，仓库执行事实仍由 WMS 提供，不能重新引入 Shopify 首期交易依赖。

## 交互骨架

- 顶部固定 ALSVID 品牌与一级导航；
- 点击一级模块后，左侧纵向显示该模块的详细二级菜单，右侧为工作区；
- 不使用永久固定的传统左侧一级菜单；
- 首页工作台聚焦运营概览、待办、异常与关键业务数据；
- 使用共享 `AppShell`，移动端将导航收纳为菜单。

## 一级导航

工作台、产品研发、商城运营、经销商管理、生产制造、库存管理、跨境物流、采购管理、客户与车主、售后服务、财务管理、经营分析、设置。

## 业务范围

- 产品：平台、型号、版本、SKU、BOM、零部件、技术资料、工程文件；
- 订单：B2B、销售、生产需求、配件与售后订单，以及履约状态；
- 生产：计划、任务、装配、QC、VIN、序列号、出厂与追溯；
- 库存：成品、半成品、零件、仓库、出入库、调拨与预警；
- 经销商：档案、区域、授权等级、采购与销售关系；
- 客户：档案、车辆绑定、购买、保修与服务记录；
- 售后：VIN 查询、保修、维修工单、配件申请、知识库与服务统计；
- 供应链：供应商、采购、来料检测、评价与成本分析；
- 数据：销售、生产、库存、售后与经销商分析；
- 设置：用户、角色权限、审计、集成与环境。

车辆全生命周期是生产、客户与售后共用的业务对象，不单独形成一级导航。Admin 不复制 WMS 的仓库执行或 PSP 的支付处理能力，页面无真实业务事实时保持明确空状态。列表默认使用高密度表格；新增/编辑使用简洁弹窗或快捷表单，不再为业务记录制作演示卡片详情页。
