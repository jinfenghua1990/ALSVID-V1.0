# Admin 中文优先及仓库删除
Admin 内部后台以简体中文为唯一默认 UI 文案语言；新增、编辑、删除、操作反馈均使用中文，不增加英文/德文界面切换。规范代码（SKU、ISO、仓库编号、API 路径）保留原格式，WWW 多语言前台保持不变。

仓库设置新增“删除”，首次点击进入二次确认弹窗，须手动输入匹配的完整仓库编号。服务端授权 `warehouse.manage` 并在事务中锁定仓库及所有库位，检查非零库存、活动预留、历史出入库、预留历史、盘点和第三方仓映射。存在任何关联则返回 409 冲突，不修改库存、订单或流水。只有真正从未使用过的空仓才允许删除空库位及仓库档案，记录权限审计；其他表 FK 限制仍然保护业务记录，冲突转化为可读提示。
